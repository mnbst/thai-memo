# 例文プール確認の記録

pool-review スキルで確認待ち（Firestore `pool_review`）をさばいた結果。NG にした文と、直してから入れた文の傾向を追う。
確認のたびに上の表へ1行、下へその回の明細を足す。プロンプトを直す・直さない判断は `prompt-effect-ledger` に書く。
プールを後から手で直した履歴は `docs/pool_fix_log.md`。

分類（1文1つ、いちばん重いもの）:

| 分類 | 中身 |
|---|---|
| 不自然なタイ語 | 連語・語順・欠けた語・文体の混在で、母語話者が言わない形 |
| 場面として言わない | 文法は通るが、その状況でその内容を言わない |
| 学習語が文に合わない | key_word を残す限り自然な文にならない（NG にするしかない） |
| 訳の欠落 | 機能語・移動動詞（มา/ไป）・副詞・主語の意味が訳にない |
| 訳の付け足し | タイ語にない意味（性別・頻度等）を訳で足した |
| 訳のずれ | 時制・文の種類（命令/平叙）・係り方を取り違えた |
| 単語分解 | word_breakdown の意味・注記がその文での働きと違う |
| 発音 | pronunciation の欠落・誤り |
| relation 不整合 | context.relation と文体・終助詞・呼び方が食い違う |

## 2026-10-27 prod premium ja/en（78件、うち en 10件）

Claude と Codex で全件を見て、指摘のあった文に修正案を作った（直した文は Codex にもう一度見せ、残った指摘も直した）。そのうえで生成プロンプトのルール（空白は最大1つ・指示詞は名詞から切る・文末詞が無いのに訳に終助詞を付けない・原文に無い勧誘を足さない・relation と人称／文末詞の一致）と照合し、当たった文も直した。ユーザー指示で、修正案のある文は修正して入れ、残りはそのまま入れ、NG 推奨の1件だけを弾いた。

  単語分解（品詞の取り違え）が 0→12 件。ไป を副詞、พรุ่งนี้/ตอนนี้ を接続詞、ถ่ายรูป を前置詞にする誤りが繰り返し出る。relation 不整合は 10→1 件に減った。
  「時点」（timeFrame）の抽選値と文が食い違う文が3件（#13・14・58）。文は優先度どおり時点を落としていて、食い違いは context に抽選値が残るため。アプリは timeFrame を表示しないので直さず入れた。
